## 本地启动

完整账号版需要 Node.js 24+ 和 pnpm：

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:4190 。本地测试数据库保存在已排除 Git 的 `.local/`。默认每日 5 个新词，可在计划中调整。

```sh
pnpm test
pnpm build
```

仅预览访客静态页面可运行 `python3 -m http.server 4173 --directory dist`，此方式不支持账号 API。部署和环境变量详见 [ACCOUNT_DEPLOYMENT.md](ACCOUNT_DEPLOYMENT.md)。

## 已实现

- 15 本课程入口；零基础 8 词、中考 10 词、高考 10 词，另有雅思基础 3632 词条、进阶 100 词；全站去重 3671 词。原精选 220 词 / 235 词义各有 3 条双语例句；新增 3451 个上传词条明确标记缺例句。其余 10 本明确显示词库待补充。
- 每日新词额度、目标完成日期、暂停/恢复、全词库到期复习优先；跨课程共享词义进度。
- 新词严格走裸词 → 例句 → 详解；后续轮次例句 → 详解。
- 按词义计数；曾“不认识”的词义需要不同轮次累计三次认识；改判回退本次；详解和继续不计数。
- 先穿插其他词；同词收尾时等待 8 秒并主动进入下一轮，避免连点刷过。轮次例句从三条中轮换。
- 详解显示本句译文、各常用词义及例句、形近词/近义词/词族或其他关系对比，关联词不自动入队。
- 新词按预编关联组排列；复习打乱。组大小随可用示例与当日数量变化。
- 当天不再自动刷已通过词义；按逐级提示评级安排跨日复习，自测依赖用户真实判断，不是科学验证的掌握判定。
- 原示例词的今日文章按预编段落组合；包含新雅思词时降级为明确标注的独立语境例句合集（不是连贯文章），覆盖当天实际触及的去重词汇，绑定当日所学词义；高亮、点击释义、翻译、全文朗读。新增任务后重新生成，避免旧覆盖率。
- 最多 10 题的四选一听力；优先薄弱词义；原文辅助单独记录；错题次日复习与当天主动加练；累计当日各次测验数据。
- 当前卡片、选择、队列、收尾等待、文章、测验题序、答案都保存在本机；支持备份导入导出。导入替换需确认。
- 响应式页面、键盘可达控件、原生模态框、减少动态效果支持、异常提示。
- 可选 WebMCP 三个工具：读取进度、设置每日额度、开始/继续学习，不代用户判断认识。

## 演示边界

- **未接入 OpenAI 或其他 API**，无需密钥。`.env.example` 仅说明以后服务端接入的预留变量；本版本不会读取这些变量，不要把密钥写进静态页面。
- 文章是原创预编片段组合，测验是预编题库，不是实时 AI 生成。结构、词汇覆盖和选项唯一性可自动检查；语义准确性目前为作者审核，尚未外部词典逐条认证。上线完整词库前需要权威来源、版权及人工审校。
- 发音与朗读使用设备的 `speechSynthesis`。浏览器不支持、没有英文语音或系统播放失败时可显示原文辅助；无法保证每台设备都有相同音色或真正离线的语音。
- **支持真实账号和自动云同步**。访客数据仍独立保存在浏览器，登录后可主动导入账号。未同步的本机记录需备份；本地预览与正式服务器使用独立数据库。
- 登录用户的学习快照保存到本站 Cloudflare D1 数据库，没有分析追踪。访客记录仅在用户主动导入后上传。
- 本地存储损坏时保留旧数据，不会自动覆盖；页面提示可导出当前会话。可导入有效备份恢复保存。

## 文件结构

- `dist/data.js`：词库与课程。词义 ID 为跨课程共享键。
- `dist/engine.js`：可独立测试的学习状态机、排队与跨日调度。
- `dist/content.js`：演示文章、覆盖检查与测验出题。
- `dist/app.js`：页面、事件、持久化、朗读和可选 WebMCP。
- `dist/style.css`：电脑、平板、手机布局。
- `tests/learning.test.mjs`：关键业务规则与内容完整性测试。
- `.openai/hosting.json`：Sites 项目标识与静态输出目录。

## 雅思 GT 半年学习工作台（2026-10-22）

默认首页为 `#ielts`，按培训类、每周 12 小时、六个日历月建立计划，可在设置中调整为 10 小时。完整可打印计划在 `#ielts-plan`；时间分配为听力 270、写作 240、口语 120、阅读 90 分钟。四科起点需要实际诊断，不根据四六级成绩推算。

新增听力精听笔记、本地音频、GT 书信与 Task 2 原创练习、双稿保存与固定初稿、计时器、口语本地录音、阅读证据笔记、错因复盘、主动词块间隔回忆及模考记录。正常语音录制需要浏览器支持 MediaRecorder、HTTPS/localhost，并由用户主动授权麦克风；不支持时用手机录音。录音和音频只存在内存，刷新前下载录音，音频需重选。

雅思数据单独保存在 `lexiday.ielts.v1`，旧词库数据 `lexiday.v1` 不迁移、不覆盖；两个模块分别导出备份。草稿输入后自动保存，倒计时刷新后按真实截止时间恢复。清除浏览器数据会丢失本机记录，请定期导出。登录后支持账号同步；未实现语音转写或 AI 评分，无需 AI API key。正规整套试题由用户自备或前往官方资料页；站内题目明确标为原创练习。

模考稳定性检查只计完整、首次、限时、无辅助的记录，重复材料去重。GT 阅读训练线 36/40、听力 32/40；写作与口语需要外部反馈，自评分不计入稳定性证据。这些是学习检查点，不是考试分数预测。

验证：`npm test` 包含 35 项测试；覆盖旧词卡流程、日期与时长分配、三套新卷要求、GT/A 阅读区分、外部反馈条件、无辅助条件、计时恢复及词块回忆。浏览器验证初稿输入/锁定/刷新恢复与响应式布局。麦克风实际录制依赖用户设备及授权，未自动开启用户麦克风。

## 系统语法课堂

入口 `#grammar`（主导航“语法课堂”）。4 个阶段、16 节原创基础课、96 道随堂题和 48 道独立阶段题（每节课及阶段测验各三套）。每课按规则、例句、易错点三步学习；随堂 2/2 通过，每阶段四课通过后解锁测验，3/4 通过。未答题不能跳题，提交后锁定答案并显示解析，可完整重练；保留历史通过状态，错题记录累计次数与纠正状态。

`lexiday.grammar.v1` 独立本机存储保存课程位置、讲解步骤、已选选项、已提交答案、测验结果及错题。再次进入语法模块自动恢复当前视图，目录可点击“继续上次学习”。支持独立 JSON 导出/导入；导入先校验再确认替换。损坏备份不会覆盖当前数据，存储异常会显示提示。登录后支持账号云同步，访客换设备请使用备份。

新增 10 项语法测试，合计 45 项通过。浏览器验证：讲解步骤刷新恢复、错题解析刷新恢复、重练通过后进入下一课；原单词和雅思测试继续通过。
