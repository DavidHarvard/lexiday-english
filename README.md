# 词序 Lexiday

## Cambridge IELTS 4 全套听力判分（2026-10-29）

Test 1–4 的全部 16 个 Section、160 个题号已接入“检验答案”，每段独立显示逐题反馈和 10 题得分。答案来源为用户指定的 IELTS EXTREMES 四个 Test 页面，每段提供对应来源链接；按原网页编号保存的答案在 `data/imports/cambridge-4-listening-answers.json`，运行 `node scripts/build-listening-answers.mjs` 可重建前端答案文件。

判分保留原题号 1–40，支持网页列出的替代答案及可选词、大小写与空格、千位分隔符、数字范围和常见日期写法。Test 1 第 11 题及 Test 3 第 35 题要求两个空全部正确；Test 3 第 38、40 题的两字母答案不限顺序。Test 2 第 25–26、39–40 题及 Test 4 第 39–40 题每题号填一个字母，可交换顺序，相同字母只计一次。按当前题页的每个题号计一分；单题双空或多选均需全部正确。

答案继续沿用原有按音频 ID、题号保存的雅思 notes，支持现有备份和账号同步。修改作答后重新点击“检验答案”。网页只是判分参考来源，并非本站自行听校或官方成绩评定。

## 本地启动

完整账号版需要 Node.js 24+ 和 pnpm：

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:4190 。本地测试数据库保存在已排除 Git 的 `.local/`。默认每日 5 个新词，可在计划中调整。

```sh
pnpm test
pnpm build
```

仅预览访客静态页面可运行 `python3 -m http.server 4173 --directory dist`，此方式不支持账号 API。部署和环境变量详见 [ACCOUNT_DEPLOYMENT.md](ACCOUNT_DEPLOYMENT.md)。

## 已实现

- 15 本课程入口；零基础 8 词、中考 10 词、高考 10 词，另有雅思基础 3632 词条、进阶 100 词；全站去重 3671 词。原精选 220 词 / 235 词义保留 3 条双语例句；雅思两本词库全部 3655 词及 25 个额外关联词补齐结构化词性、释义和例句，每个整理义项至少两条。其余 10 本明确显示词库待补充。
- 每日新词额度、目标完成日期、暂停/恢复、全词库到期复习优先；跨课程共享词义进度。
- 新词严格走裸词 → 例句 → 详解 → 听音输入中文验证；单词与例句自动朗读，后续轮次重新提供例句。
- 按学习词义计数；曾“不认识”的词义需要不同轮次累计三次听音输入正确，视觉自评和查看详解不计通过。
- 先穿插其他词；同词收尾时等待 8 秒并主动进入下一轮，避免连点刷过。轮次例句从至少两条独立语境中轮换。
- 详解显示本句译文、各常用词义及例句、形近词/近义词/词族或其他关系对比，关联词不自动入队。
- 新词按预编关联组排列；复习打乱。组大小随可用示例与当日数量变化。
- 当天不再自动刷已通过词义；按逐级提示与中文输入结果安排跨日复习；主动选择“完全记住”的词退出新学和复习，可在学习报告恢复。
- 原示例词的今日文章按预编段落组合；包含新雅思词时降级为明确标注的独立语境例句合集（不是连贯文章），覆盖当天实际触及的去重词汇，绑定当日所学词义；高亮、点击释义、翻译、全文朗读。新增任务后重新生成，避免旧覆盖率。
- 最多 10 题的四选一听力；优先薄弱词义；原文辅助单独记录；错题次日复习与当天主动加练；累计当日各次测验数据。
- 当前卡片、中文输入草稿、听音结果、选择、队列、收尾等待、文章、测验题序、答案都保存在本机；支持备份导入导出。导入替换需确认。
- 响应式页面、键盘可达控件、原生模态框、减少动态效果支持、异常提示。
- 可选 WebMCP 三个工具：读取进度、设置每日额度、开始/继续学习，不代用户判断认识。

## 演示边界

- **未接入 OpenAI 或其他 API**，无需密钥。`.env.example` 仅说明以后服务端接入的预留变量；本版本不会读取这些变量，不要把密钥写进静态页面。
- 文章是原创预编片段组合，测验是预编题库，不是实时 AI 生成。结构、词汇覆盖和选项唯一性可自动检查；本次按源词表逐项整理原创教学释义与例句，疑难词参考词典核对，不等同于权威词典全文或穷尽所有专业义项。
- 发音与朗读使用设备的 `speechSynthesis`。浏览器不支持、没有英文语音或系统播放失败时可显示原文辅助；无法保证每台设备都有相同音色或真正离线的语音。
- **支持真实账号和自动云同步**。访客数据仍独立保存在浏览器，登录后可主动导入账号。未同步的本机记录需备份；本地预览与正式服务器使用独立数据库。
- 登录用户的学习快照保存到本站 Cloudflare D1 数据库，没有分析追踪。访客记录仅在用户主动导入后上传。
- 本地存储损坏时保留旧数据，不会自动覆盖；页面提示可导出当前会话。可导入有效备份恢复保存。

## 文件结构

- `dist/data.js`：词库与课程。词义 ID 为跨课程共享键。
- `dist/engine.js`：可独立测试的学习状态机、排队与跨日调度。
- `dist/content.js`：演示文章、覆盖检查与测验出题。
- `dist/app.js`：页面、事件、持久化、朗读和可选 WebMCP。
- `dist/style.css`：电脑、平板、手机布局。
- `tests/learning.test.mjs`：关键业务规则与内容完整性测试。
- `.openai/hosting.json`：Sites 项目标识与静态输出目录。
