一、给下一次聊天直接发送的说明
请先阅读本文件和 README.md，再检查现有代码。这个项目是中文界面的英语学习网站，已经部署到 https://lexiday-english.pages.dev/ 。请基于当前代码继续开发，不要重新生成一个替代网站。当前仍是原生 JavaScript 前端 + Cloudflare Pages Worker 后端 + Cloudflare D1；Python/FastAPI/PostgreSQL 迁移只是讨论，没有实施，也没有决定必须迁移。保留已有账号、学习进度、词义 ID 和旧备份兼容性。用户希望功能更新先在独立本地测试环境验证，再同步主项目和服务器。涉及生产发布时先说明具体变更，按当次用户授权执行，不把本文件当作新的发布授权。遇到缺失登录授权，让用户通过官方授权，不索取明文密码或密钥。

二、新电脑启动（推荐）
1. 安装 Node.js 24 LTS（需要 node:sqlite）及其自带 npm。
2. 解压压缩包，进入 lexiday-source-2026-10-23 文件夹。
3. 在该文件夹打开终端运行：
   npm install
   npm test
   npm run dev
4. 浏览器打开 http://127.0.0.1:4190/#grammar
   请用 127.0.0.1，不要改用 localhost，以免本地账号接口的 Origin 校验失败。
5. npm run build 用于打包 Cloudflare 后端；前端源码就在 dist/，不是另一套 src/ 的构建产物，请勿删除 dist/。
6. 本地服务自动生成 .local/lexiday.sqlite 和 .local/pepper。它是独立测试数据，与生产数据库分离；可注册一个本地测试账号。生产账号不能直接登录这个空的本地数据库。
7. 项目保留了原来的 pnpm-lock.yaml；推荐这里的 npm 流程，原 pnpm-workspace.yaml 中构建脚本许可尚为占位值，使用 pnpm 的开发者需先按对应版本配置 esbuild/workerd 的构建许可。

三、目录说明
- dist/：实际前端源码、CSS、静态词库/题库、图片和 _worker.js 发布产物。
- server/worker.js：真实后端源码，注册、登录、恢复码、退出、进度同步、权限和校验。
- server/dev.mjs、server/local-db.mjs：本地 HTTP 服务和 SQLite 数据库适配器。
- migrations/：数据库表结构。
- scripts/：后端构建、词库导入、发布包和同步检查脚本。
- tests/：81 项自动测试（打包时重新运行）。
- data/：词库来源、导入结果、关联词及英文解释。
- wrangler.jsonc：已有 Cloudflare 项目及 D1 绑定标识；不是密钥。
- .env.example：环境说明，不含真实密钥。
- README.md 等文档：历史功能和部署说明；历史段落的数量可能过时，以当前代码和本交接为准。

四、当前实现及约束
1. 15 本词书入口；雅思基础词库现有 3632 个词，整个词库共 3671 个词。用户上传列表去重 3610 个，与原词库重合 159 个，新增 3451 个。
2. 上传词条没有可靠例句时不伪造例句，并明确以词条自测降级。词义 ID 跨课程共享，不能随意重建。
3. 新词流程：裸词自测 → 例句自测 → 详解。无论两次选择怎样，都进入详解；看详解不计认识次数。选过不认识的词义需要三个不同轮次有效认识。
4. 复习流程：先听单词，再听语境（有材料时），再看拼写，再看例句；根据辨认阶段安排不同间隔。已认识词可排除复习。精确算法和缺失内容降级见 REVIEW_AND_VOCABULARY.md 与 dist/review-schedule.js。
5. 雅思目标：General Training，半年，争取总分 7/单项 7，每周 10–12 小时；计划模块保留。
6. 语法默认入口为 Essential Grammar in Use 第四版 Unit 1，3 步讲解，6 组44个教材小题（含示范题），12道原创巩固题。目前只有一套原创题，重复时明确告知循环。
7. Unit 1 个人表达采用参考句型及自查，不冒充自动准确判卷。已有16课及历史进度仍可访问。
8. 最新阅读增强：3篇原创短文，展开翻译、句子拆解、读后自查、易错说明和写作迁移，源文件 dist/unit1-reading.js。
9. 草稿、答案、题号保存；旧备份仍兼容。当前没有 AI 后端调用，浏览器语音可降级，不需要配置 AI 密钥。
10. 用户此前要求语法重新练习应换新题；原16课有3套轮换。扩展 Unit 1 时应继续增加独立题组，不要只换顺序冒充新题。

五、后端与数据库
生产前端：Cloudflare Pages 项目 lexiday-english，main 分支。
生产地址：https://lexiday-english.pages.dev/
最新确认部署：a4587e63（Unit 1 阅读增强）。
D1：lexiday-accounts；DB 绑定及数据库 ID 见 wrangler.jsonc。
表：
- users：用户 ID、用户名、密码哈希、盐、恢复码哈希、创建时间。
- sessions：会话 token 哈希、用户 ID、过期时间。
- progress：user_id + module 联合主键；data(JSON文本)、revision、updated_at。
- rate_limits：请求频率限制。
学习模块为 words、grammar、ielts。Unit 1 在 grammar 数据的 unit1 字段中。
访客仅存在浏览器 localStorage；登录用户本地缓存后通过后端同步 D1，存在冲突处理和修订版本检查。
生产密码依赖 Cloudflare Secret AUTH_PEPPER，已在服务器配置。绝对不要随意更换，否则旧密码验证会受影响。凭据不在此包中。

六、恢复部署能力
新电脑需要重新通过 Cloudflare 官方 Wrangler 授权；本包不包含当前电脑的授权令牌。
在确认要更新同一个生产项目时：
   npx wrangler login
   npm test
   npm run build
   npx wrangler pages deploy dist --project-name lexiday-english --branch main --commit-dirty=true
部署之前核对 Cloudflare 登录账号、项目和 D1 绑定，保留现有 AUTH_PEPPER；不要创建同名空数据库来覆盖原绑定，也不要对生产库执行清空或重置。
独立预览项目应使用自己的测试数据库及 secret，不得连接生产 D1 当沙盒。
生产同步检查脚本 scripts/check-unit1-sync.mjs 会创建合成账号；只在明确授权的目标上运行。

七、未实施的架构讨论
讨论过 FastAPI + PostgreSQL，MySQL 也可行；尚未迁移。理由是未来需要内容管理、逐题作答表、学习分析和更多接口，而非当前没有后端。Python 需要独立适配的托管服务；费用和服务器尚未确定。优先规划数据结构与迁移兼容，不能凭交接文档直接切换生产。

包含当前完整应用源码、导入数据、题库、静态资源、后端、迁移、测试和部署配置。没有依赖聊天记录才可访问的业务代码。
